# AI Backend: Three Checks Before You Ship: style auditions

Same 0–15s speech excerpt. Local code visuals; no paid generation. These are creative trials, not reviewed finals.

1. **Product UI** (tech-ui) — Cursor triggers a focused interface reveal. Best for: Product demos and tech explainers. Assets: Code-drawn UI; optional official product captures.

2. **One continuous world** (continuous-world) — One camera travels through a persistent world. Best for: Connected systems and feature journeys. Assets: Code-drawn world; optional product screenshots.

3. **Editorial paper collage** (paper-collage) — Torn cutouts assemble into a causal editorial composition. Best for: History, comparisons and evidence-led stories. Assets: Local paper geometry now; optional licensed photos and cutouts.

4. **Brush character story** (brush-story) — An original character acts out the problem and builds the solution. Best for: Concepts with a character and emotional payoff. Assets: Code-drawn character now; optional custom painted model sheet.

5. **Cinematic blueprint** (cinematic-blueprint) — Mapped camera push, layered depth and traced architecture. Best for: Systems, architecture and dramatic reveals. Assets: Code geometry; optional licensed environment textures.

Select with: npm run styles -- select backend-checklist --style <id>
Then ask Codex or Claude to extend the chosen direction through the full transcript.
