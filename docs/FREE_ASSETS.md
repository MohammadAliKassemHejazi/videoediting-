# Free assets and motion sources

User discovery library: https://polyfork.dev/assets?price=free
The browser tool could not load this site; a subsequent shell fetch loaded the
directory. Inspect each selected asset's own download/license before using it.
No Polyfork asset is bundled or claimed acquired.

Alternatives inspected on 2026-10-13:
- Poly Haven, https://polyhaven.com/license — CC0 asset library for HDRIs, textures
  and models; use official downloads and store the specific asset URL/license.
- Kenney, https://kenney.nl/assets — inspect the license on each chosen asset pack.
- Three.js, https://threejs.org/docs/ — local MIT runtime installed; examples may
  include separately licensed models/textures, so check their individual provenance.

The current story demos use original procedural geometry plus downloaded CC0
Poly Haven lighting and wood. `assets/story-library/SOURCES.json` records the exact
files and source URLs. Both user directories were subsequently fetched locally;
their directory pages are discovery resources, not licenses for every linked file.
This keeps character identity deterministic. Future films should use
licensed library assets when they improve the actual setting or explanation.
