# Tech Video Studio

Read [AGENTS.md](AGENTS.md) for the maintained architecture and creative contract.
Use [README.md](README.md) for commands and [docs/WORKFLOW.md](docs/WORKFLOW.md)
for production. The same project workflow applies to Claude and Codex.

Use `studio.mjs` and the existing Canvas/Playwright/FFmpeg renderer. Preserve
approved cuts and source footage. Design each topic from its actual speech,
review the muxed draft, and deliver the final video with a generated thumbnail.
The `.claude/skills/` integration remains available for Claude.
