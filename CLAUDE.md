# Tech Video Studio

Read [AGENTS.md](AGENTS.md) for the maintained architecture and creative contract.

For original footage-free style films, read `docs/ORIGINAL_STYLE_FILMS.md`.
The three independent examples live under `projects/` and have separate live
Remotion folders and material sound scores. Reuse their chosen feeling through
fresh scenes. Avoid routing new scripts through the same demo plot or card layout.
Use [README.md](README.md) for commands and [docs/WORKFLOW.md](docs/WORKFLOW.md)
for production. The same project workflow applies to Claude and Codex.

Use `studio.mjs` and the existing Canvas/Playwright/FFmpeg renderer. Preserve
approved cuts and source footage. Design each topic from its actual speech,
review the muxed draft, and deliver the final video with a generated thumbnail.
The `.claude/skills/` integration remains available for Claude.

Open `npm run preview` before video edits and leave Remotion visible. Use the actual
installed motion packages and read docs/STYLE_LAB.md or docs/STORY_STUDIO.md as
appropriate. Offer 5–10 different 15-second styles, then extend the chosen concept.
For scripts, produce educational 3D, illustrated stories or cinematic story animation
with selectable English/Arabic generated voice and persistent series characters.
All new video exports are 2K/60fps; story drafts last at least a minute. Full-screen
storytelling is the default; split-screen is optional. Research recent examples,
make the narrative coherent, inspect the actual renders and finish authorized work.
User preferences in AGENTS.md override upstream defaults and automatic paid setup.
`npm run skills:check` verifies the shared Codex/Claude skill packages.

Read docs/REFERENCE_AND_STORY_EDITS.md for the independent collage, Clawd brush,
3D paper-theatre and reference/hand-tracked clip workflows. Use their dedicated
render commands. The warm-creature-story skill adds an original keyframe and
ComfyUI/Blender production path; real furry animation still needs animated shots.
Keep that limitation visible. Related creature episodes reuse series/ember-luma.
